# ClamAV Desktop

一个面向 Ubuntu 的轻量 ClamAV 图形入口。界面采用暖白背景、橙色强调和卡片式菜单，软件名与桌面图标保持英文。

## 功能

- 扫描下载目录；
- 扫描个人文件，并在存在 `/data` 时一并扫描 data 盘；
- 自行选择扫描目录；
- 使用管理员权限进行深度全盘扫描，并跳过 `/proc`、`/sys`、`/dev`、`/run`、`/snap` 等虚拟或重复目录；
- 扫描前统计文件，显示真实的文件数量和百分比进度；
- 发现可疑文件时只报告，不自动删除；
- 病毒库每天检查更新 4 次；
- 扫描记录保存在 `~/.local/state/clamav-manual-scan/`。

## 安装

Ubuntu 24.04 或更新版本：

```bash
git clone git@github.com:latebird06/My-Tool.git
cd My-Tool/clamav-desktop
./install.sh
```

安装脚本会通过 Ubuntu 软件源安装 ClamAV、病毒库更新服务和 GTK 4 依赖，然后创建应用菜单入口与桌面快捷方式。安装过程中需要输入系统密码。

## 使用

从桌面或应用菜单打开 **ClamAV**，选择扫描范围。深度全盘扫描需要管理员授权，耗时和磁盘负载也明显高于普通扫描。

扫描结果中的“未发现威胁”只代表当前病毒库没有匹配到已知特征，不能代替软件来源核验、系统安全更新和重要文件备份。

## 卸载桌面界面

```bash
./uninstall.sh
```

卸载脚本只移除本项目提供的图形界面、图标和快捷方式，不会卸载系统 ClamAV，也不会删除扫描记录。
